# Ноутбуки

[01_rcaeval_eda.ipynb](01_rcaeval_eda.ipynb) содержит три части:

- Структурные проверки всех 90 инцидентов: качество, временное покрытие, объём и наличие сервисов в каждом источнике.
- Сравнение метрик, логов и длительностей операций до и после сигнала на development. Для каждого источника используются только случаи с полным пятиминутным окном с обеих сторон.
- Подробный разбор одного выбранного development-инцидента.

Разбиение 54/18/18 сохранено. На validation и test выполняются только заранее заданные структурные проверки, без подбора диагностических правил.

Из корня репозитория:

```bash
uv sync --locked --group eda
```

В VS Code откройте ноутбук и выберите `.venv/bin/python` как ядро. Запускайте из папки `notebooks/` или корня проекта. Затем выполните все ячейки по порядку. Если нет манифеста или одного из перечисленных файлов, запускается загрузчик. При наличии набора ноутбук работает без сети. Для другого подробного примера измените `CASE_ID`, выбрав случай из `dev_cases`.

Загрузить данные отдельно можно командой `uv run --frozen --group eda python scripts/download_rcaeval.py`.

Данные находятся в `data/raw/rcaeval/`, которая исключена из Git. Загружаются 90 инцидентов RE2-OB и общий индекс `cases.parquet`, всего около 923 МБ. Скрипт фиксирует ревизию `afeacb11bcc94dadfd1c8f483ee4377b2b8b614e`, проверяет размеры и контрольные суммы файлов и сохраняет `download_manifest.json`. Повторный запуск использует кеш загрузки.

Источник: [RCAEval на Hugging Face](https://huggingface.co/datasets/phamquiluan/RCAEval/tree/afeacb11bcc94dadfd1c8f483ee4377b2b8b614e).

Каждый инцидент обрабатывается отдельно. Сводные показатели не взвешиваются числом строк телеметрии. Повторы одного сценария не считаются независимыми подтверждениями; оценка качества агента ещё впереди.
